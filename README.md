##### Venix Manga API
[**Live Demo (Swagger UI)**](URL_TO_YOUR_LIVE_API/docs/) | [**Repository**](https://github.com/ricdemgtz/portfolio/tree/main/API/Venix)

![Venix API Swagger UI](URL_TO_A_SCREENSHOT_OF_YOUR_SWAGGER_UI)

A RESTful API designed to manage a comprehensive collection of manga, authors, and genres. Built with Flask and Flask-RESTX, it provides a well-structured and documented backend service, including interactive documentation through Swagger UI. The entire application is containerized with Docker for easy deployment and scalability.

**Key Features:**
* **Full CRUD Functionality:** Create, Read, Update, and Delete operations for mangas, authors, and genres.
* **Interactive API Documentation:** Automatic Swagger UI generation at the `/docs/` endpoint for easy testing and exploration.
* **Advanced Filtering and Search:** Endpoints to list mangas with pagination, filtering by status or genre, and a full-text search endpoint.
* **Containerized Environment:** Fully configured with `Dockerfile` and `docker-compose.yml` for consistent development and deployment environments.
* **Data Validation:** Robust server-side validation to ensure data integrity.

**Technologies Used:**

##### API Venix Manga
[**Ver Demo en Vivo (Swagger UI)**](URL_DE_TU_API_ONLINE/docs/) | [**Ver Repositorio**](https://github.com/ricdemgtz/portfolio/tree/main/API/Venix)

![Venix API Swagger UI](URL_A_UNA_CAPTURA_DE_PANTALLA_DE_TU_SWAGGER_UI)

Una API RESTful diseñada para gestionar una colección completa de mangas, autores y géneros. Construida con Flask y Flask-RESTX, provee un servicio backend bien estructurado y documentado, incluyendo documentación interactiva a través de Swagger UI. La aplicación completa está contenerizada con Docker para facilitar su despliegue y escalabilidad.

**Características Principales:**
* **Funcionalidad CRUD Completa:** Operaciones de Crear, Leer, Actualizar y Eliminar para mangas, autores y géneros.
* **Documentación Interactiva de API:** Generación automática de Swagger UI en el endpoint `/docs/` para facilitar las pruebas y la exploración.
* **Filtros Avanzados y Búsqueda:** Endpoints para listar mangas con paginación, filtros por estado o género, y un endpoint de búsqueda de texto completo.
* **Entorno Contenerizado:** Totalmente configurado con `Dockerfile` y `docker-compose.yml` para entornos de desarrollo y despliegue consistentes.
* **Validación de Datos:** Sólida validación del lado del servidor para garantizar la integridad de los datos.

**Tecnologías Utilizadas:**
